使用说明

这是一个多板块笔记站，主要能力：
  1. 侧拉分区栏：板块/分区/标签面板默认收起，鼠标碰到屏幕左边缘会滑出，松开一会儿自动收起；点顶部 ☰ 可 固定显示，再点一下取消固定；点空白区域或按 Esc 关闭。左侧腾出的宽度全部给笔记卡片。
  2. 板块（最上层分类）：抽屉顶部一排板块签——高数 / 线代 / 概率论 / 自控…点签即切换「页面」，每个板块的分区、标签、笔记完全独立；点末尾 ＋ 新建板块 自行添加（新板块自动带一个默认分区），右键板块签改名，悬停 🗑 删除板块（其下分区和笔记整体移到相邻板块，不会丢）。
  3. 分区 + 标签：所在板块的抽屉里自建分区（如「错题截图」「公式推导」，新建/重命名时可选择所属板块，即整区跨板块搬移），每条笔记可打多个标签，点标签即筛选。分区管理：鼠标悬停侧栏分区条目会出现 🗑 删除按钮——分区里的笔记会自动移到同板块相邻分区，不会丢；右键分区条目可重命名。
  4. 卡片底色：编辑笔记时可在「卡片底色」里挑 16 种柔和底色（点 ✕ 恢复默认白底），底色按笔记保存，导出 / 导入都会带上。
  5. 放图片 + 调显示大小：新建笔记时点虚线框选图或直接拖入，可给每张图设「图片说明」。每张图的显示大小可单独控制——在笔记卡片里把鼠标移到图片上，拖右下角的小方块手柄即可实时改大小；或在编辑笔记时用 缩略 / 小 / 中 / 大 / 满宽 预设和宽度滑块设定。大小按张保存，导出 JSON 也会带上。还能在编辑器「图片位置」里选图片排在文字上方或文字下方（按笔记保存，默认下方）。
  6. 正文编辑器：工具栏一键排版——H₂ 标题、B 加粗、I 斜体、1. 有序列表、• 无序列表、❝ 引用、</> 行内代码、Σ 公式（选中文字再点会包成 $...$）、🖼️ 添加图片、🖍 高亮、✕ 清除格式；点 👁 预览渲染效果（公式/高亮照常显示）。支持直接粘贴 Markdown 原文（# 标题、**加粗**、*斜体*、- 列表、1. 列表、> 引用、`行内代码` 自动转成排版），也可以直接粘贴截图（图片会进下方图片列表）。编辑区右下角可拖拽调高。
  7. LaTeX 公式：行内写 $...$ 或 \(...\)，独立成行写 $$...$$，卡片里自动渲染成公式（编辑框内显示源码）。首次渲染需联网加载 MathJax，之后同会话离线可用。公式里的小于/大于号建议写 \lt / \gt。
  8. 图片识别（OCR）：正文工具栏 📷 打开识别面板——把教材/笔记截图直接 Ctrl+V 粘贴（或点击选图/拖图），文字与公式一起转成 LaTeX，可在结果框修改后一键插入正文或复制。识别后端：通用 AI 视觉接口（**厂商管理器**：左侧厂商列表、右侧该厂商独立的 Base URL / API 格式 / API Key / 模型列表——各厂商配置互不干扰，改动自动保存；「＋ 添加厂商」内置 18 家预设一键填好地址：智谱/DeepSeek/硅基流动/通义/豆包/混元/千帆/Kimi/阶跃/零一/MiniMax/OpenAI/Anthropic/Gemini/Groq/Grok/OpenRouter；「查询模型」用该厂商的 Key 拉取可用模型）或 SimpleTex（专业公式模型）。Key 只保存在本机浏览器。
  9. 搜索：顶部搜索框检索标题、正文、标签。
  10. 导出 / 导入：右上角导出为一份 JSON（含图片），换设备或备份用；导入可还原。
  11. 自由布局（防堆叠）：工具条 ▦ 网格 / ❏ 自由 切换。自由模式下按住卡片标题栏拖动、拉边缘改大小；块之间不重叠——一旦会压到别的笔记就停在那个位置、过不去，也不会推挤对方。新建笔记会自动找空白处落下。若已有笔记叠在一起，点工具条的 ✧ 整理布局（仅自由模式显示）可一次性把它们散开。位置自动保存。
图片存哪里？
你在网页里添加的图片保存在浏览器本地数据库（IndexedDB），不会让 HTML 文件变大，刷新/重开都在。
如果想把图片落成文件放进本站同目录的 imgs/ 文件夹，用导出 JSON 里的图片，或在笔记里下载单张图后手动存入 imgs/。
后续让大模型塞笔记：
把整理好的笔记（文字 + 图片文件）交给大模型，模型会把图片放进 imgs/ 目录，并把内容写入 HTML 顶部的 EMBEDDED_NOTES / EMBEDDED_SECTIONS 数据区；本站打开时会自动合并这些内置笔记（按 id 去重，不会重复）。 分区可带 boardId 指定所属板块，省略则进第一个板块。
